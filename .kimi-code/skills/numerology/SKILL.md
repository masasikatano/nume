# 数秘術領域知識

nume のドメイン（ライフパスナンバー）に関する知識。

## 計算ルール（`src/lib/numerology.ts`）

- 生年月日 `YYYY-MM-DD` の**全桁を合計**し、1〜9 の一桁に還元する
- **マスターナンバー（11/22/33）は非採用**。途中で出ても最後まで還元する
- 計算例: `1985-04-23` → 1+9+8+5+0+4+2+3=32 → 3+2 = **5**
- `calcLifePath(date: string): number` と `isValidBirthdate(date: string): boolean` は純関数で、**クライアント（NumeApp）とサーバー（reading.ts）で同一モジュールを共用**。計算ロジックの二重実装・ズレは禁止

## バリデーション

- 受付範囲: 1900-01-01 〜 当日。日付として無効（例: 2020-02-30）も拒否
- 不成立は 400。`<input type="date">` 側でも min/max を設定済み

## コンテンツ

- ナンバー1〜9のキーワード・意味・特徴・強み・注意点・相性は `src/lib/numberData.ts` の手書きテンプレートが正。**LLM は使わない**
- 結果画面の大表示（ナンバー＋一言キーワード）も numberData 由来
- `/numbers/[n].astro` はこのデータを prerender して解説ページを生成

## プロンプト方針（`src/lib/prompts.ts`）

- 役割: 温かく、押し付けがましくない数秘術の占い師
- 入力: 生年月日と算出済みライフパスナンバー。「計算はサーバーが正」とし、LLM に計算させない・計算説明をさせない
- 出力構成: ①ナンバーの意味 ②性格・強み ③恋愛・対人関係 ④仕事・使命 ⑤今意識したいこと。800〜1200字、見出しや箇条書きなしの自然な文章
- 禁止事項: 病気・死期・金額の予言、専門助言への踏み込み、「必ず」「運命だ」等の決定的表現
- 末尾に免責文を含める指示

## トーンと免責

- 決断を迫らず、前向きに自分を語るきっかけを与える
- 免責（「エンターテインメント・内省のきっかけであり、専門的な助言ではない」）は LLM 出力末尾と画面の結果エリア下部の両方に常時表示
